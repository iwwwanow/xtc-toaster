Последние два коммита в её remote не попали, поэтому `git branch -d` отказался удалять, хотя они уже были в master. Удалили через `-D` после `merge-base --is-ancestor`.

Но новый образ в ghcr не даёт Renovate события, поэтому PR появится только на плановом прогоне Mend. Ускорить можно галкой в Dependency Dashboard (issue #3 в infra). ## Решения по бэклогу

В релиз (`docs/planning.md`, спринт 5, «added before the release»):

- **undo / redo** — сделано в тот же день, `docs/diary/2026-11-10_undo-redo.md`.
- **delay** — на проводе параметра (`param → delay → track`, параметр читает дорожку на `frame − d`). Строки как у `layers`, чтобы один delay обслуживал несколько параметров. `d` один на ноду, в первой версии не анимируется.
- **Нода, брошенная на провод**, встаёт в разрыв. **Провод, брошенный на ноду**, подключается к её входу.
- **Alt + тянуть** — копия. Выделение рамкой с Shift пользователя устраивает, его не меняем, Ctrl+D не делаем.
- **Удаление ноды сохраняет цепочку**: A → нода → B становится A → B. **Зоны действий** внизу экрана, пока ноду тащат, — пока одна, `delete`.
- **Группы + value** — «самая жирная фича». Первая версия согласована: группа из выделения кнопкой на панели над выделением, без горячих клавиш; один пиксельный вход и один выход; без вложенных групп; экземпляры связаны. Оценка 4–6 дней, 13–20.11. QA спринта 6 из-за этого сдвигается примерно на 21–25.11. Если не успеваем, группы уходят в 1.1: в тосте это необязательное поле, так что миграция не нужна.

Отложено или закрыто:

- **Duplicate отложен.** Пользователю пока непонятно, как он выглядит. Строить его поверх групп.
- **Одна дорожка на несколько параметров — закрыто.** Хрупко (разные единицы, группа, имя строки), ту же задачу закрывает value.
- **Composer как рамка — закрыто**, его закрывают группы.
- **Список нод и скролл дорожек с прозрачными проводами отложены.** Скролл реален (своё ребро `LinkEdge`, нагрузка — доли миллисекунды на кадр), но нода и без него работает хорошо.
- **Новые идеи на после релиза:** аудио → готовые time-window через ноду-анализатор (`docs/backlog/2026-11-10_audio-to-time-windows.md`, бывшая «нода true / false») и главное меню — сетка проектов с превью (`docs/backlog/2026-11-10_main-menu-projects-grid.md`).

Важное уточнение по формату: по правилу из CLAUDE.md новое необязательное поле и новый тип ноды формат тоста не ломают. Поэтому группы, value и delay не обязательно решать до заморозки 1.0. В заметках от 09.11 сказано, что решать надо до 1.0, — это было слишком строго.

Из техдолга до релиза предлагал: проверку `imageId` в репозитории uploads, лимит слоёв на клиенте, аллокации в горячих циклах lib (около 2–3 ч, главная цена кадра), таймаут на зависший рендер. Пользователь по ним ещё не решил, в planning они не внесены. Третий тост из «3 toasts» до сих пор нигде не определён.
