# 2026-11-09 — расширение спринта 5 перед релизом: таймлайн blender, экспорт mp4, группы, ширины нод

Сессия планирования, без кода. Ветка `feat/animation-server`. Must спринта 5 закрыт: degas анимирован, пользователь прогнал его на локальном стеке, всё работает (`docs/diary/2026-11-08_degas-animated-elk-arrange.md`). До релиза пользователь попросил добавить ещё четыре фичи. Спецификация — `docs/sprints/sprint-5.spec.md`, раздел «extension 09.11».

## Что решено

- **Таймлайн как в blender.** Берём перетаскивание playhead и транспорт целиком: `start` / `‹ key` / `‹` / `play` / `›` / `key ›` / `end` и поле кадра. Ключи можно перетаскивать, провод параметра, брошенный на `+ track`, создаёт связанный трек. Горячие клавиши работают только при выбранной ноде animation. Зум: по умолчанию fit, Ctrl+колесо, кнопка `fit`. Раскладка повторяет blender, но вместо иконок кнопки с текстом. Таблица соответствия blender → наше — в спеке.
- **Группы треков** по ноде-источнику. Каждая группа — fieldset с видом рамки ноды. У группы есть строка-сводка с ключами всех её треков, и перетаскивание ключа в сводке сдвигает все ключи группы на этом кадре. Группу можно свернуть. Контракт не меняется: группы выводятся из связей.
- **Выпадающий блок экспорта** под `render animation`: формат `gif` / `mp4` и `loop`. `loop` уходит из ноды в тост, в новое поле `ToastGraph.export` (выбор пользователя: в файле тоста, а не в ноде и не только в браузере). В режиме `seconds` есть чекбокс `whole cycles`, по умолчанию включён. Включён — длина округляется до целых циклов. Выключен — длина ровно `seconds`, последний цикл обрезается на кадре.
- **Ширины по сетке uiu.** Нода занимает одну колонку owo — 190px. Подпись числового поля переезжает внутрь поля, как в нодах blender. Нода animation — 6 колонок, 1236px: 396 на каналы, 808 на таймлайн. `layers`, `input` и `output` — по 2 колонки. Последнее я выставил по умолчанию, пользователь не спрашивался.

Чем это перекрывает прежнюю спеку: mp4 больше не stretch, группы (stretch 2) и перетаскивание ключей (stretch 6) вошли в работу. Правило 03.11 «на ноду ничего не бросается» теперь не действует для `+ track`.

## Подводные камни на реализацию

- Сейчас xyflow по Delete удаляет выбранную ноду. Пока выбран ключ, Delete должен удалять ключ, поэтому Delete у xyflow на это время выключается.
- В свёрнутой группе handle треков переезжают на строку легенды, иначе провода повиснут в пустоте.
- В старых файлах `loop` лежит в ноде, а zod молча отбросит этот ключ. Миграции не будет (до 1.0 это нормально). У degas `{ seconds: 15 }` переносится в `export` вручную.
- Для yuv420p в mp4 нужен чётный размер кадра — делаем pad. Ещё надо проверить, что в ffmpeg из debian trixie есть `libx264`; если нет, берём `libopenh264`.
- Подпись внутри поля шириной 174px длинные метки не вмещает (`x (% of width)` → `x %`), длинная форма уходит в `title`.
