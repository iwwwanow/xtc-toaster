# 2026-11-10 — Alt + тянуть ноду — копия

Пятая фича из блока «10.11 added before the release» (`docs/planning.md`). Решение — `docs/backlog/2026-10-28_box-select-like-illustrator.md`, раздел 10.11: рамку выделения не меняем, берём только Alt + тянуть. Ветка `feat/undo-redo`, в master не слита.

## Как сделано

- **Подмена ролей.** Как в Illustrator: оригинал со связями остаётся, копия едет за курсором. Но xyflow тащит те ноды, что уже есть, и подменить перетаскиваемую на лету нельзя. Поэтому копией становится сама перетаскиваемая нода. На `onnodedragstart` с `event.altKey` на исходных местах ставятся новые ноды с новыми id, тем же `data` (через `structuredClone`) и `selected: false`. К ним переходят все связи, выходящие за перетаскиваемый набор. Связи внутри набора остаются у перетаскиваемых нод и клонируются между оставленными. Граф из оставленных нод совпадает со старым с точностью до id, а у перетаскиваемых только связи между собой. Пользователь id не видит, так что для него это неотличимо.
- **Правила — `leaveCopiesBehind(nodes, edges, dragged, newId)` в `graph.ts`**, чистая функция, генератор id подставляется в тестах. Input, output и animation (одна на граф) не копируются. Если они в выделении, то просто едут, а их связи с копируемыми нодами считаются внешними и переходят к оставленным. Если копировать нечего, возвращает null, и это обычное перетаскивание. Провода параметров к дорожкам animation тоже внешние, остаются у оригинала: у копии анимации нет.
- **История.** `session.dragging` ставится в том же обработчике, до копирования, поэтому копия, перетаскивание и возможная вставка в провод записываются одним шагом после отпускания.
- **Вместе с броском на провод.** Перетаскиваемая копия без пиксельных связей, поэтому `linkUnder` / `insertOnLink` её принимают. Alt + тянуть на провод вставляет копию в разрыв, а оригинал остаётся на месте.

## Проверено

- Typecheck всех пакетов. Тесты web — 179 (+4): одна нода (оставленная копия забирает все связи, включая провод параметра к дорожке; перетаскиваемая — без связей); две (внутренняя связь остаётся и клонируется, внешние уходят к оставленным); у копии своё `data`; input / output / animation не копируются. Каждый результат проходит `validateGraph`. Тесты остальных пакетов зелёные.
- Headless Chrome, `?toast=more-nodes`, Alt через `modifiers` у `Input.dispatchMouseEvent` (скрипт `alt-copy.ts` в scratchpad сессии):
  - связанная tint: на месте осталась tint с новым id и связями `ho → tint`, `tint → op`, уехавшая — без связей; один Ctrl+Z вернул всё;
  - свободная fill брошена с Alt на `ti → op`: копия встала в разрыв (`ti → fi`, `fi → op`), а на старом месте осталась свободная fill; один Ctrl+Z;
  - skew + corners выделены (Ctrl+клик; xyflow берёт Ctrl из keydown, не из модификаторов мыши): скопированы обе, `sk → pe` уехала с ними, оставленные держат цепочку `in → sk' → pe' → ho`; один Ctrl+Z.
