## Renovate на infra

- Mend: «Renovate Only» (не «Mend Application Security» — платная лицензия), режим «Scan and Alert» (а не «Scan Only» по умолчанию — это silent, без PR), только репо `infrastructure`, план Community.
- `renovate.json`: `enabledManagers: [docker-compose]`; свои образы `ghcr.io/iwwwanow/**` — automerge (`automergeType: pr`, `ignoreTests`: тесты прошли в CI приложения до публикации образа, а на PR в infra своего CI нет); owo — `allowedVersions: "<2"` (решено: evix не закрепляем на 1.7.0, обновляется в пределах 1.x).
- Гонка при установке: первый прогон открыл onboarding PR за 17 с до пуша конфига; второй закрыл его сам.
- Первый настоящий бамп — owo evix 1.7.0 → 1.12.0: PR смержен за 2 с, doco-cd выкатил за ~20 с, старый образ удалён (`prune_images`, по умолчанию true).
- Провайдер Timeweb (`terraform/versions.tf`) Renovate видит, но с нашим конфигом не трогает. Решено: подключать только вместе с `tofu plan` в CI — пока apply руками, PR ради редкого бампа (1.8.0–1.8.3 за всё время) — лишняя работа (infra planning).
- Задержка: Renovate мгновенно реагирует только на события в самом репо (пуш, правка issue, PR) — новый образ в ghcr такого события не даёт, его видно только на плановом прогоне Mend. Все прогоны сегодня — `requested` (установка, пуши, галочка), по расписанию ещё ни одного. Галочка «Check this box…» в Dependency Dashboard (#3) — ручной запуск, Renovate снимает её после прогона; поставить можно через `gh issue edit`. Ускорение на потом — CI приложения ставит галочку сам (infra planning, «Задержка»).

## Откат

`git revert` коммита PR #4 → пуш 17:00:39 → `0.2.0` `healthy` в 17:01:25 (45 с). Renovate сразу открыл бамп заново (PR #5), но **automerge выключил сам**: «a matching PR was automerged previously». Значит, настоящий откат — revert + закрыть такой PR без мержа (Renovate пропустит эту версию до следующей). Здесь версия была хорошей — PR #5 смержен руками, `0.2.1` вернулся в 17:02:46. На PR в infra есть одна проверка — GitGuardian (приложение на аккаунте); на automerge не влияет.

doco-cd в логах ругается «skipping file that could not be decrypted» на чужие `secrets.sops.*` (ключ RU не в получателях) — это предупреждения, на деплой не влияют.

> Как это работает: картинка проходит через цепочку блоков слева направо (шум по цвету → выделение по оттенку → поворот в перспективе). В блоке input загружаешь картинку — только jpg или png и не больше 2 мегапикселей (примерно 1600×1200), большие нужно сначала уменьшить; фото с телефона может оказаться повёрнутым, это известный баг. > Что написать (в свободной форме): что было непонятно или где застряла; понравилось ли что-то из получившегося, пригодилось бы тебе такое; чего не хватило. Можно скинуть сами картинки.
