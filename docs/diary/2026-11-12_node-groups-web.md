# 2026-11-12 — группы нод: web

Продолжение `docs/diary/2026-11-11_node-groups.md`: contract и сервер были готовы, сегодня сделан web. Ветка та же, `feat/groups`, не слита. Правила ui записаны в `docs/sprints/sprint-5.spec.md`, раздел «node groups», подраздел «web (12.11)».

## Как устроено

- **Состояние.** В `session` теперь отдельно корень (`rootNodes` / `rootEdges`) и определения `groups`: у каждого свои ноды xyflow с позициями и свои связи. Плюс вид — корень или id группы. `session.nodes` / `edges` стали аксессорами текущего уровня. `SvelteFlow` по-прежнему делает `bind:nodes={session.nodes}`, а весь прежний код (связи, бросок на связь, удаление с сохранением цепочки, Alt+drag) работает на открытом уровне без правок. `imageId` и `animationNode` берутся только из корня.
- **Scope.** Все проверки правки в `graph.ts` (`canConnect`, `insertOnLink`, `linkOntoNode`, `keepChain`) получили последний параметр `scope`: функцию, которая вставляет уровень обратно в весь тост. `scopeOf(flow, group)` для корня добавляет определения, а для группы — корень и остальные определения, так что связь внутри группы проверяется вместе со всеми её экземплярами. По умолчанию стоит `ROOT`, поэтому старые тесты не менялись.
- **Рендер.** `graph` — весь тост с группами, `expanded = expandGroups(graph)`. Кадр, `drivenValues` и `hasAnimatedParams` строятся по развёрнутому графу. Внутри группы `driven` считается по самому определению: там видно, что дают его собственные value / factor. Ошибка рендера на `<экземпляр>/<нода>` переводится на экземпляр (`instanceOf`), а output называет её именем группы (`nodeLabel`).
- **Сохранение и история.** В `toSaved` добавлены группы и `groupPositions` (позиции внутри, по id группы). Снимок истории — весь тост, вид в него не входит. После undo вид остаётся, если группа ещё есть, иначе показывается корень. `measured` / `selected` сохраняются на всех уровнях (`keepUi`).
- **`web/src/groups.ts`** — чистые функции: `groupSelection`, `ungroup`, `exposedParams`, `paramBoundsOf`, `ownParamValue`, `nodeLabel`, `nextGroupName`, `createInstance`, пункты меню `group:<id>`.
  - `groupSelection` проверяет границу выделения. Пиксели могут входить только от одного источника и выходить только из одной ноды. Провода параметров наружу становятся выведенными параметрами (`x`, `x 2`). Провод параметра снаружи внутрь и delay наружу — отказ. В конце новый тост проходит `validateGraph`.
  - `ungroup` — это contract `expandGroups` для одного экземпляра. Для этого у `expandGroups` появились опции `only` (какие экземпляры разворачивать) и `id` (какие id дать копиям), так что логика разрешения связей не дублируется.
- **Ноды и панели.** `GroupNode` (экземпляр): легенда — имя группы, поле на каждый выведенный параметр, `open`; двойной клик по рамке, но не по полю, открывает группу. `GroupInputNode` / `GroupOutputNode`; output перечисляет выведенные параметры. `GroupPanel` — `toast › имя`, имя можно править, рядом число экземпляров. `SelectionToolbar` — `NodeToolbar` xyflow над выделением, кнопки `group` / `ungroup` / `open` и причина отказа. В левом меню раздел `groups`: перетащить — ещё экземпляр, `×` — удалить группу без экземпляров. Внутри группы меню не даёт `animation` и группы. У каждого уровня свой viewport, при первом входе — `fitView` (xyflow сам ждёт замера нод).
- **Подписи анимации.** `paramLabel`, `trackName`, `trackGroups`, `delayRowName` и `paramValue` принимают группы. Дорожка на параметре экземпляра попадает в канал с именем группы, первый ключ берёт собственное значение экземпляра.

## Найдено по пути

- **Дыра в contract.** Связь из экземпляра по несуществующему параметру (или в именованный handle его входа) проходила `validateGraph`: `expandGroups` её молча выбрасывал. Теперь `groupsIssue` отказывает: «not a param of this group» / «a group has one input». Тесты в contract и `tests/toasts/broken-group-unknown-param.json`.
- **Наложение animation на output после импорта** было и раньше (тост `animation` выглядит так же): output вырастает, когда приходит картинка, уже после elk. К группам это не относится, не трогал.

## Проверено

- Typecheck всех пакетов. Contract 236 (+3), web 219 (+26, `groups.test.ts`): создание (границы, отказы, имена, рендер тот же после разворачивания), ungroup (id, свои значения, раскладка), связи внутри группы через scope, параметры экземпляра, каналы дорожек, сохранение с группами, раскладка определения. Тестовые тосты импортируются, `broken-*` отказываются.
- Headless Chrome на dev-стеке (порт 5174, CDP):
  - `?toast=group`: два экземпляра со своими значениями, анимированное поле заблокировано; двойной клик → внутри group input / output и путь, `toast` → обратно, картинка на месте.
  - `?toast=animation`: move + opacity (Ctrl+клик) → `group` → один экземпляр с `x`, `y`, `opacity`, три дорожки в канале `group 1`, картинка та же; `ungroup` → обе ноды назад; два undo → группа, потом исходный граф.
  - Меню: экземпляр, брошенный на связь, встал в неё. Правка rotate внутри группы поменяла картинку. После удаления всех экземпляров цепочка осталась (in → out), `×` удалил группу.
  - Подводный камень: xyflow ловит Ctrl для множественного выделения по `keydown`, а не по флагу мыши, поэтому в CDP нужен `Input.dispatchKeyEvent`.
