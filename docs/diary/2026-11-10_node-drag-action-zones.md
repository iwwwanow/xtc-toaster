# 2026-11-10 — зоны действий при перетаскивании ноды

Седьмая фича из блока «10.11 added before the release» (`docs/planning.md`). Идея — `docs/backlog/2026-11-10_node-drag-action-zones.md`. Ветка `feat/undo-redo`, в master не слита.

## Как сделано

- **`panels/DragZones.svelte`** — `Panel` внизу по центру с одной зоной `delete`. Видна, только пока тащат ноду и в наборе есть удаляемая: `deletable !== false`, то есть не input / output. Стиль только из uiu: в покое `btn_ai-generated btn-dashed_ai-generated`, под курсором `btn-danger_ai-generated` (красная). Своего CSS нет, `TODO(uiu)` не нужен. `pointer-events: none`: зона ничего не ловит сама, попадание считает Editor.
- **Editor.** `onnodedragstart` решает, показывать ли зону. `onnodedrag` проверяет курсор по rect зоны (`pointOf` — мышь или касание). Над зоной провод под нодой не предлагается (`dropLink = null`): зона главнее. `onnodedragstop` над зоной вызывает `deleteElements({ nodes })` для всех перетаскиваемых нод — тот же путь, что у правого клика. Поэтому input / output пропускаются, если затесались в выделение, а цепочка сохраняется через `ondelete` → `keepChain`.
- **История.** `deleteElements` асинхронный, ноды и связи меняются через микрозадачу после `dragging = false`. Шаг пишется после 300 мс тишины, поэтому перемещение и удаление попадают в один шаг. Undo возвращает ноду на исходное место.
- Зона лежит поверх нод (у панелей xyflow z-index выше): нода, протащенная на неё, уходит под зону. Пользователь будет перерисовывать ui сам, так что оставил так.

## Проверено

- Typecheck, тесты всех пакетов зелёные (логика целиком в Editor, чистой функции нет: попадание в rect, удаление — `deleteElements` + уже протестированный `keepChain`).
- Headless Chrome, `?toast=more-nodes` (скрипт `drag-zone.ts` в scratchpad сессии): до перетаскивания зоны нет. Пока тащат matrix — `btn-dashed`, над зоной `btn-danger`, проводов не подсвечено. Отпущена над зоной: matrix удалена, `pe → ti`, зона пропала. Один Ctrl+Z вернул всё. Перетаскивание input зону не показывает. Скриншот смотрел: красная `delete` внизу.
