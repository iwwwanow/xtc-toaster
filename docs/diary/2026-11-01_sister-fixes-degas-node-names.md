## Быстрые фиксы сестры (stretch 1)

- **Граф переживает перезагрузку.** `packages/web/src/persist.ts`: граф с картинкой и позициями нод сохраняется в `localStorage` (задержка 300 ms, чтобы не писать на каждый кадр перетаскивания). При загрузке проходят те же проверки, что у импорта тоста. Если что-то не так (старый формат, ручная правка), открывается граф по умолчанию. Если доступа к хранилищу нет (приватное окно), редактор работает, просто ничего не помнит. Если картинка на сервере истекла по TTL, на input показывается обычный `image not found`.
- **`clear graph`** оставляет input → output, картинка остаётся. `confirm()` не используем: первый клик «взводит» кнопку на 3 с (`sure? click again`), второй сбрасывает.
- `Controls` в правом нижнем углу, версия переехала в левый нижний.
- **Лимит загрузки только в MB.** Пользователь хотел мегабайты, как везде. Сервер на самом деле режет по пикселям (2 MP) и по байтам (10 MB), поэтому сообщение примерное: `too large: max ≈ 1 MB`, из расчёта 0.5 MB на мегапиксель jpeg. Оговорка: png того же размера в пикселях проходит при нескольких MB, а сильно сжатый jpeg на 4 MP весом меньше 1 MB не пройдёт.
- **Подсказки** у export / import / clear на tooltip из uiu. Библиотека не понадобилась, задержку 500 ms даёт `transition: visibility 0s 500ms` на hover, исчезает подсказка сразу. Но uiu открывает tooltip только вверх-вправо, у правой панели он уходил за экран. Поэтому `.tooltip-left` / `.tooltip-right` написаны в `app.css` с `TODO(uiu)`, пробел записан в `docs/backlog/2026-10-30_uiu-gaps-from-web.md`.

## degas t = 0 как граф (stretch 3)

`toast-1_degas/toast.json`: 7 строк layers, 26 нод. Perspective и translate стоят в identity, это заготовка под анимацию спринта 5. Тост экспортируется из barrel как `toast1degas` через `graph.ts`, CLI-скрипт `index.ts` не трогали.

Первый хэш с golden не сошёлся. Сравнил послойно: расходятся только слои с маской, и только после perspective. Причина: скрипт при `t = 0` ставит углы на `width` × `height`, а сервер переводит 100 % в последний пиксель (`width − 1`), чтобы нетронутые углы давали точную identity. Получается, кадр `t = 0` в скрипте растянут в `w / (w − 1)` раз. Когда в граф подставили пиксельные углы скрипта и радиусы blur под poppies (1 / 1 / 0), хэш совпал бит в бит. Это закреплено в `packages/server/tests/degas.test.ts`. Значит, оба отличия сидят в данных тоста, а не в рендере. Blur в контракте задаётся в px, а скрипт считает его в % от ширины, поэтому в тосте 8 / 4 / 2 под картинку шириной около 1600 px.

Попутно:

- `?toast=<имя каталога пресета>` в dev открывает и пресеты (`toast-1_degas`, `toast-2_signac`). Список всех `?toast=` в `tests/toasts/README.md`.
- **Авто-раскладка.** Нода встаёт в ряд того, что она тянет, если ячейка свободна. Иначе 7 цепочек разной длины перекрещивались.
- **fit view после import / `?toast=` / clear** через счётчик `session.replaced`. Два подводных камня. Первый: `minZoom` у xyflow по умолчанию 0.5, и в него упирается fitView на большом графе; опустил до 0.1. Сначала я ошибочно подумал на момент вызова и полез в `useNodesInitialized`. Второй: `fitView` внутри `$effect` читает ноды и зацикливает effect, нужен `untrack`.
- Для degas в dev нужен `RENDER_MAX_LAYERS=8` в `.env`, при запасном лимите 4 будет ошибка `over 4 layers`. На проде уже стоит 8.

## Одно имя нод во всём стеке (stretch 4, шире плана)

План был «меняем только ui-лейблы, тип в контракте не трогаем» (решение 26.10: тип записан в файл тоста). Пользователь не захотел расхождения client / server / lib, переименовали везде:

`hueMask → selectColor`, `saturationMask → selectVivid`, `valueMask → selectBright`, `isolateChannel → channel`, `hueNoise → colorNoise`, `translate → move`, `yRotation → turn3d`, `perspective → corners`, `homography → matrix`, `composer → layers`. Надпись в UI — то же имя словами (`turn3d` читается «3d turn»).

- **lib плоская**, одна нода — один метод `Layer`: `selectColor()`, `blur()`, `move()`, `corners()` и т.д. вместо `mask` / `applyEffect` / `setTransform`; `setOpacity → opacity`. Файлы сервисов остались сгруппированными, внутренняя математика сохранила свои имена (`applyHomographyTransform`, `boxBlur`). Единицы прежние, lib-овские (px, допуски 0–1), перевод из процентов и мм делает сервер.
- **skew:** у lib `tx` наклонял горизонтали, сервер передавал оси накрест. Теперь `x` наклоняет вертикали во всех слоях.
- **Проверка:** golden-хэши lib и тест degas прошли без обновления снапшотов, пиксели не изменились.
- **Меню** разбито на группы select / color / effect / move / layers: подписанный разделитель uiu `.hr_fieldset` и подсказка в одну фразу на каждую ноду (`NODE_HINTS`, `NODE_CATEGORIES` в `web/src/graph.ts`).
- `TOAST_GRAPH_VERSION` остался 1, миграции нет. Старые файлы тостов не откроются, сохранённый в браузере граф сбрасывается на граф по умолчанию (проверено).

## Подписи fieldset как в uiu, прокрутка меню

После мержа пользователь показал, как в uiu оформлена подпись: `<fieldset class="hr_fieldset"><legend><h6>…</h6></legend></fieldset>`. Все `legend` в приложении (рамки нод, меню, разделители групп) переведены на `<legend><h6>`: курсив, тонкое начертание. Подвох с размером: `h6` в uiu задан как `1.4em` от корня 10px, а у нас body `1.4rem`, поэтому подпись выросла бы до ~20px. Добавил `legend { font-size: 1rem }`, теперь `h6` — 14px, как в uiu.

Меню нод перестало помещаться, сделал вертикальную прокрутку (`.node-menu`: `max-height` по высоте окна, тонкий scrollbar `--LIGHT`). Подвох: контейнер с прокруткой обрезает CSS-tooltip uiu, который открывается вправо за его край. Поэтому подсказка в меню — один элемент `.fixed-hint` с `position: fixed` в виде `tooltip__content`. Координаты ставит JS: от правого края меню (не пункта, иначе подсказка ложится под scrollbar) и от середины пункта по высоте. Задержка 500 ms через `animation`, подсказка пропадает при уходе мыши, прокрутке и перетаскивании. `.tooltip-right` больше не нужен, удалён. Оба пробела дописаны в `docs/backlog/2026-10-30_uiu-gaps-from-web.md`. Проверено в headless Chrome на окне 1100×600: меню прокручивается, подсказка видна целиком.
