# uiu: таймлайн ноды анимации

Стили таймлайна (`.animation*` в `packages/web/src/app.css`, помечены `TODO(uiu)`) написаны вручную: в uiu нет линейки, строки с дорожками, ключа-ромба и playhead. Если таймлайн понадобится не только этой ноде, их стоит перенести в uiu отдельным компонентом. Пока нода одна, переносить рано: вид ещё не проверен на 24 дорожках degas и может поменяться.
