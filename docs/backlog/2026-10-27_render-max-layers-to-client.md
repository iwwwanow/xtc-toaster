# Лимит слоёв `RENDER_MAX_LAYERS` — отдавать клиенту

В спринте 4 лимит знает только сервер (env `RENDER_MAX_LAYERS`, fallback 4, считается по всем composer одного рендера). Web о нём не знает: `+` в composer добавляет строки без ограничения, а о превышении пользователь узнаёт уже из `render-error`. Решение 27.10: так и оставить на спринт 4, но потом лимит нужно передавать клиенту и блокировать `+` (или подсвечивать превышение) ещё до рендера.

Варианты доставки: поле в `/healthz` или отдельный конфиг-эндпоинт (`GET /api/config`), либо первое сообщение по ws после подключения. В любом случае это изменение contract (новая схема или новый тип серверного сообщения). Лимит общий на рендер, а не на ноду, поэтому web придётся считать подключённые строки по всем composer графа, в том числе вложенным.
