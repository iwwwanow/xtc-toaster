# Аренда GPU для рендера самописного софта

Мысль на потом: как гонять тяжёлые рендеры (видео 4K/8K, печать в огромном разрешении, большие серии вариаций) на арендованном GPU, если рендерер свой. Готовые рендер-фермы (RebusFarm, GarageFarm, Fox Renderfarm) не подходят — принимают только стандартный софт (Blender, Houdini, Cinema 4D, V-Ray). Инструменты для такой схемы пришли из ML, поэтому примеры искать у ML-инженеров и technical artists из VFX. Прежде чем арендовать — посчитать покупку своей карты: облако оправдано только для разовых тяжёлых задач. Связано с `2026-10-06_native-backend-zig-skia-migration.md` и `2026-08-31_final-render-export-stack-architecture.md` — до GPU-бэкенда вопрос неактуален.

## Схема

Инстанс поднимается под задачу, отрабатывает её и удаляется, всё через API провайдера. Руками не делать: рано или поздно забудешь выключить.

- **Образ** — рендерер + зависимости + CUDA runtime (драйвер уже на хосте) в Docker, приватный registry (GHCR / Docker Hub private). Держать компактным: время скачивания оплачивается.
- **Данные** — через S3-совместимое хранилище (AWS S3, Backblaze B2, Cloudflare R2): контейнер забирает сцену, рендерит, выгружает результат.
- **Оркестратор** — локальный скрипт: создаёт инстанс, ждёт результат в bucket, удаляет инстанс.
- **Страховка** — watchdog внутри контейнера сам удаляет инстанс по завершении или по таймауту + лимит расходов в аккаунте.
- **Stop ≠ terminate** — остановленный инстанс часто продолжает списывать за диск или резерв GPU. Только удалять.

## Приватность

- Во время работы код и данные расшифрованы в памяти — root на хосте теоретически может их достать.
- P2P-маркетплейсы (Vast.ai — дёшево) — чужие машины, чувствительное туда не нести. Датацентровые провайдеры (RunPod Secure Cloud, Lambda, CoreWeave, AWS, GCP, Azure) дают юридические гарантии и нормальную изоляцию. Confidential computing на H100 — дорого, скорее всего не нужно.
- Секреты не класть в образ — env vars или secret manager; ключи к хранилищу с минимальными правами.
- Наружу только SSH по ключу; связь с домашней сетью — VPN (WireGuard, Tailscale).
- В образ — скомпилированный бинарник без исходников.

## Оркестрация

- **SkyPilot** — основной кандидат (open source, autostop / `--down`).
- **Serverless GPU** (RunPod Serverless, Modal) — посекундная оплата, ноль в простое; минусы — холодный старт и лимит длительности задачи.
- Terraform для пакетного рендера избыточен; Deadline — студийная очередь рендера, для справки.

## Первый шаг

Упаковать рендерер в Docker и добиться, чтобы «вход из bucket → выход в bucket» работал локально без ручного вмешательства. Потом выбрать SkyPilot или serverless по длительности одной задачи: короткие — serverless, длинные — SkyPilot.
