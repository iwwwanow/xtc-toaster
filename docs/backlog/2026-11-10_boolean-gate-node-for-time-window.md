# Нода с выходом true / false, которая прерывает time-window

Идея пользователя от 10.11, пока очень сырая. Нужна нода, которая выдаёт булево значение true / false. Этот выход подключается к time-window в animation-node. Когда значение false, окно прерывается, и его цепочка в этих кадрах не работает. Значение может переключаться с заданной частотой, тогда окно мигает или режется на куски по ритму. Идея опирается на time-window, а их пока нет (`docs/backlog/2026-11-03_timeline-time-windows.md`). Кроме того, в графе появится первый не числовой тип параметра, поэтому форму стоит прикинуть до того, как 1.0 заморозит формат тоста.
