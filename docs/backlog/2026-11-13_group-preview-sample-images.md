# Превью группы: показательные картинки на входе, результат на выходе

Идея пользователя (13.11): внутри группы не видно, что она вообще делает с картинкой. Внутри видны только ноды и провода, а результат — только в output тоста, через все остальные ноды. Предложение: заготовить набор показательных картинок, например градиент, цветовой круг, фото, сетку, текст. В group input их можно переключать, а в group output видно, как картинка выглядит после преобразований группы. Сейчас group input внутри группы картинки не имеет: пиксели приходят от экземпляра. Поэтому превью — это отдельный рендер определения с выбранной картинкой и значениями параметров по умолчанию (или выбранного экземпляра). Он не трогает рендер тоста и ничего не сохраняет в формат, разве что выбор картинки как настройку вида. Рядом лежит preview-нода — картинка в любой точке цепочки, `docs/backlog/2026-10-26_preview-node-and-export-settings.md`. Превью группы может стать первым её частным случаем.
