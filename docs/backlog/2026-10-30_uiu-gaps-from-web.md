# Пробелы uiu, найденные при переводе web на uiu

Всё, что `packages/web/src/app.css` пишет руками с пометкой `TODO(uiu)`, нужно перенести в `../iwwwanow_uiu`, выпустить новый тег и поднять его здесь. После этого локальное правило удаляется. Найдено 30.10 на uiu `v0.3.0` (ветка `feat/uiu`).

- **Базовый размер текста.** owo ставит `:root { font-size: 62.5% }` и задаёт размер только для `p` / `h*`, поэтому весь остальной текст получается 10px. В uiu нужен `body { font-size: 1.4rem; line-height: 1.6rem }` — тот же масштаб, что у компонентов `_ai-generated`.
- **reset против svg.** Правило `svg { max-width: 100%; height: auto }` в reset owo сжимает до нулевой ширины svg с `overflow: visible`, у которого размер родителя 0. Так пропадают все провода xyflow. Варианты: убрать `max-width` для `svg` в reset (оставить только для `img`) или исключить `svg[overflow]` / `svg:not([width])`.
- **Fieldset с рамкой.** `.hr_fieldset` в owo — это разделитель, а не рамка. Нужен блок вроде `.fieldset_ai-generated`: 1px `--LIGHT`, при hover / selected `--DARK`, legend как у `.hr_fieldset` (`0 4px`, lowercase, `--MEDIUM`), паддинги `--GRID-GAP-4` / `--GRID-GAP-2`, gap `--GRID-GAP-4` / `--GRID-GAP-2`, фон `--WHITE`. Здесь это `.frame`.
- **Number field как в Blender** (`.drag-field`, `nodes/Slider.svelte`). Слайдеры web на нём, `.range_ai-generated` больше не используется. Сам range тоже недоделан: дорожка 1px, а thumb 16px наезжает на подпись. Поле в размере `.input-sm_ai-generated`: значение по центру, бледная заливка `--LIGHT` показывает положение в диапазоне, на hover стрелки `‹ ›`. Перетаскивание по горизонтали (ширина поля = весь диапазон, с Shift ×0.1), клик открывает ввод. В uiu можно перенести только css, поведение — это js.
- **Строка «подпись | контрол»** (`.param`): две колонки, подпись выровнена вправо. Колонки выровнены по всей рамке через `grid-template-columns: subgrid`, рамка — grid `max-content 1fr`.
- **Color input.** В uiu его нет. Нужен в размере `.input-sm_ai-generated`, свотч без рамки, рамка 1px со сменой цвета на hover. Свотч для `::-webkit-` и `::-moz-` задаётся отдельными правилами, иначе весь список селекторов отбрасывается.
- **File input.** В uiu его нет. `::file-selector-button` нужно оформить как `.btn-sm_ai-generated`, имя файла выводить `--MEDIUM`, выключенное состояние делать пунктирной рамкой.
- **Тема для xyflow**, пожалуй, отдельным файлом (`xyflow.css`), а не в `ai-generated.css`. В ней кнопки `Controls` как `.btn_ai-generated` и `--xy-edge-stroke: --MEDIUM`. Handle: квадрат 4px `--MEDIUM`, вынесен за рамку на `--GRID-GAP-4`, зона попадания ±9px вокруг (`::before`), на hover и при валидном соединении только цвет `--DARK`. Тёмной темы в uiu нет совсем, это ещё один пробел (план спринта 4, 26.10).
- **Tooltip в другую сторону** (найдено 01.11, `feat/sister-quick-fixes`). `.tooltip_ai-generated` открывается только вверх-вправо (`left: 0`, `nowrap`), и у кнопок правой панели уходит за край экрана. Здесь это `.tooltip-left`: подсказка слева от кнопки по центру высоты, обёртка растягивается, чтобы кнопки сохраняли одну ширину. В uiu нужны модификаторы направления (`-left` / `-right` / `-bottom`) и задержка появления: здесь 500 ms через `transition: visibility 0s 500ms` на hover, исчезает сразу. Хватает чистого CSS, библиотека не нужна.
- **Размер `legend h6`** (01.11). Подпись `<legend><h6>` в uiu задана как `1.4em` от корня 10px. Здесь body `1.4rem` (см. «Базовый размер текста»), и `h6` вырос бы до ~20px, поэтому `legend { font-size: 1rem }`. Уйдёт вместе с базовым размером текста в uiu.
- **Tooltip внутри прокрутки** (01.11). CSS-tooltip uiu — дочерний элемент, и контейнер с `overflow` его обрезает (меню нод прокручивается). Здесь это `.fixed-hint`: один `position: fixed` элемент в виде `tooltip__content`, координаты ставит JS от пункта, появление через 500 ms — `animation`. В uiu стоит иметь вариант tooltip без обрезки (fixed / popover API) и тонкий scrollbar (`scrollbar-width: thin`, `--LIGHT`) у прокручиваемых панелей.
- **Кнопка с выпадающим блоком** (09.11, экспорт анимации). В uiu нет ни группы кнопок, ни dropdown. Здесь это `.export-group`: основная кнопка растягивается, рядом кнопка `▾` / `▴`, под ними настройки в рамке `.frame`. В uiu нужна группа кнопок (общая граница или зазор `--GRID-GAP-4`) и раскрывающийся блок под ней (по сути `details` / `summary` в стиле кнопки).
