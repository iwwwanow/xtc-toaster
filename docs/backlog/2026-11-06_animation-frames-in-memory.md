# Кадры экспорта анимации — в памяти или потоком в ffmpeg, а не на диске

06.11 решено для начала писать кадры `render-animation` на диск (временный каталог на томе uploads) и собирать gif из этой последовательности: в 512 MiB контейнера с пиком рендера около 430 MiB держать ролик в памяти не выйдет, а tmpfs тоже считается памятью. Как фича на потом — обойтись без диска: отдавать кадры прямо в stdin ffmpeg или держать их в памяти, когда хватит лимитов (меньше пик рендера, нативный бэкенд, больше памяти на проде). Для gif сначала нужно проверить, не держит ли однопроходный `split` + `palettegen` + `paletteuse` весь ролик внутри ffmpeg до готовности палитры — тогда stdin ничего не экономит, и нужна палитра по нескольким кадрам или два прохода.
