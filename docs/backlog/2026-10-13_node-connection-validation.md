# Валидация связей между нодами

В спринте 2 любую ноду можно связать с любой: все ноды однослойные, вход и выход у них одного типа (картинка). В спринте 4 (two-layers toast) появятся ноды с другими типами входов и выходов: композиция слоёв, blend mode. Тогда не все связи будут допустимы, и их нужно отсекать ещё в UI, а не только ошибкой рендера на сервере.

В svelte-flow для этого есть `isValidConnection`: https://svelteflow.dev/examples/interaction/validation. Правила связей лучше описать в contract (тип входа и выхода у каждого типа ноды), чтобы web и server проверяли одно и то же. Сюда же относится ветвление графа: сейчас сервер принимает только путь input → … → output без развилок.
