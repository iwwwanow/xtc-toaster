# Аудио → клип из картинок вместо субтитров

Идея на потом, не в рамках текущих спринтов. Инструмент собирается внутри xtc-toaster (как тост / набор нод), а не отдельным приложением.

## Суть

Из аудио получается видео в духе клипарта: вместо субтитров на каждом отрезке времени показывается картинка, соответствующая слову, которое в этот момент звучит.

## Флоу

1. **Аудио → субтитры.** Распознавание речи с таймкодами на уровне слов (word-level timestamps).
2. **Таймлайн слов.** Каждому таймфрейму соответствует слово (или фраза).
3. **Подбор картинок.** Меню в GUI предлагает изображения по слову текущего таймфрейма — поиск по базам (та же инфраструктура, что в инструменте для коллажей: `docs/backlog/2026-10-17_collage-tool.md`).
4. **Раскладка.** Картинку из меню перетаскивают на канвас заранее заданного размера и ставят в нужное место.
5. **Экспорт.** На выходе видео: кадры по таймфреймам + исходное аудио (сборка через ffmpeg — `assembleVideo` в lib уже есть).

## Понятия

- **таймфрейм** — отрезок аудио с одним словом, единица монтажа;
- **меню подсказок** — список картинок под слово текущего таймфрейма;
- **канвас** — кадр фиксированного размера, на котором раскладываются картинки.

## Открытые вопросы

- что видно на кадре: только картинка текущего слова или картинки накапливаются (коллаж растёт по ходу аудио)?
- гранулярность: каждое слово или только значимые (без предлогов/союзов), можно ли объединять слова в один таймфрейм?
- распознавание локально (whisper.cpp и т.п.) или через API; какие языки — ru/en?
- можно ли поправить текст/таймкоды распознавания вручную?
