# Аудио → клип из картинок вместо субтитров

Идея на потом, не в рамках текущих спринтов. Инструмент собирается внутри xtc-toaster (как тост / набор нод), а не отдельным приложением.

## Суть

Из аудио получается видео в духе клипарта: вместо субтитров на каждом отрезке времени показывается картинка, соответствующая слову, которое в этот момент звучит.

## Флоу

1. **Аудио → субтитры.** Распознавание речи с таймкодами на уровне слов (word-level timestamps).
2. **Таймлайн слов.** Каждому таймфрейму соответствует слово (или фраза).
3. **Подбор картинок.** Меню в GUI предлагает изображения по слову текущего таймфрейма — поиск по базам (та же инфраструктура, что в инструменте для коллажей: `docs/backlog/2026-10-17_collage-tool.md`).
4. **Раскладка.** Картинку из меню перетаскивают на канвас заранее заданного размера и ставят в нужное место.
5. **Экспорт.** На выходе видео: кадры по таймфреймам + исходное аудио (сборка через ffmpeg — `assembleVideo` в lib уже есть).

## Понятия

- **таймфрейм** — отрезок аудио с одним словом, единица монтажа;
- **меню подсказок** — список картинок под слово текущего таймфрейма;
- **канвас** — кадр фиксированного размера, на котором раскладываются картинки.

## Уточнения (2026-10-17)

- **На кадре много картинок**, а не одна на слово. Кадр по сути коллаж, и собирать его можно той же canvas-нодой, что и коллажи (`docs/backlog/2026-10-17_collage-tool.md`).
- **Каждый кадр уникален.** Если слово звучит долго и занимает много кадров, кадры всё равно не повторяются. Открыто, за счёт чего это достигается: смена картинок, движение/трансформации, шум и т.п.
- **Распознавание: API в приоритете, whisper (локально) — fallback.** Перед выбором изучить API-сервисы (качество, word-level таймкоды, цена) и ресурсоёмкость локального запуска на слабой машине.

## Открытые вопросы

- **Объединять ли слова в один таймфрейм.** Варианты принципа:
  - *по длительности*: при быстрой речи слово длится 150–300 мс, поэтому слова короче порога (например, 0.5 с) склеиваются с соседними;
  - *по служебным словам*: предлоги, союзы и частицы приклеиваются к следующему слову («в лесу» → один таймфрейм, картинка про лес);
  - *по фразам и паузам*: распознавание обычно и так режет речь на сегменты по паузам, тогда таймфрейм = фраза;
  - *по смыслу*: словосочетания («красный дом») — сложнее, нужен разбор текста.

  Разумный старт — длительность + служебные слова; решить на месте, посмотрев на реальный материал.
