# Нативный UI: общий Vulkan-контекст с Skia Graphite

Главный выигрыш нативного UI (например, Dear ImGui), если рендер уже на Skia Graphite (Vulkan): у UI и рендера одно `VkDevice`. Результат рендера остаётся GPU-текстурой, и нода превью рисует её напрямую. Без кодирования в png, без передачи по ws/IPC, без декодирования в webview. В RAM нет 3–4 копий кадра: при 24 Мп RGBA каждая копия весит ~96 МБ. Превью работает с минимальной задержкой, вплоть до живого рендера на каждое движение слайдера.

Цена — самая сложная часть нативного пути. Нужно завести ImGui-бэкенд (Vulkan) и Skia Graphite на одном device и queue, синхронизировать доступ к текстуре и управлять её временем жизни. Плюс C++-шим для Skia. Делать это только после переноса бэка на Zig + Skia (`docs/backlog/2026-10-06_native-backend-zig-skia-migration.md`), а сам переход оценивать по замерам: `docs/backlog/2026-10-11_desktop-iteration-roadmap.md`.

Частично выигрыш доступен и без нативного UI: Zig/Skia `.so` за Tauri-командой с сырым RGBA вместо png и превью в уменьшенном разрешении.
