# Ноды delay и duplicate — шлейф из копий

Идея пользователя 09.11, две ноды, которые, видимо, работают вместе. **Delay** подключается к ноде animation и сдвигает анимацию во времени: цепочка за ним видит дорожки на `d` кадров позже. **Duplicate** (название не утверждено) делает из одного входа N копий, а не одну. Если каждой копии дать свой delay (0, d, 2d, …) и свести копии в `layers` с убывающей opacity, получится шлейф — тот самый `trail-effect` из списка signac в `docs/planning.md`. Как это выглядит в графе и в итоговом продукте, пока непонятно. Похоже, это вариант «повторить подграф N раз с параметром `i`». На уровне контракта: копия — это `graphAtFrame` на кадре `frame − i·d`, сведённая как строка `layers`. Ограничение — `RENDER_MAX_LAYERS`: N копий дают N слоёв, и время рендера растёт с N (~1.2 с на строку на проде). Связано с группами нод (`docs/backlog/2026-11-09_node-groups-variables.md`): копировать удобнее группу, чем одну ноду.
