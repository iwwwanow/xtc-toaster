# Горячие клавиши таймлайна animation-ноды

Отложены 09.11 по решению пользователя: в релиз 28.11 таймлайн идёт без горячих клавиш, всем управляют кнопки транспорта и мышь. Задумано по образцу blender, клавиши работают только при выбранной ноде animation: Space — play/stop, ←/→ — кадр, ↓/↑ — предыдущий/следующий ключ, Shift+←/→ — начало/конец, Home — fit, I — ключ на связанных треках группы выбранного ключа (иначе на всех связанных), X/Delete — удалить выбранный ключ. Главный подвох: Delete в xyflow удаляет выбранную ноду, поэтому пока выбран ключ, Delete у xyflow надо выключать. Кнопки уже показывают будущие клавиши в `title`: пока клавиш нет, эти подсказки нужно убрать или оставить честными. Таблица соответствия blender → наше — `docs/sprints/sprint-5.spec.md`, «extension 09.11».
