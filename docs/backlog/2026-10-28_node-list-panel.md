# Окно со списком всех нод

Сырая фича под разработку. Панель со списком всех нод графа:
- клик по строке выделяет ноду точечно — удобно, когда граф большой и ноды перекрывают друг друга;
- выделенные на холсте ноды подсвечены в списке, выделение синхронно в обе стороны;
- ноды можно группировать.

Связи в списке, скорее всего, не показать — список плоский или дерево групп, а не граф.

В blender в самом node editor такого списка нет. Ближе всего:
- **Outliner** — дерево объектов сцены и коллекций, выделение синхронно с вьюпортом, коллекции служат группами. Нод node editor он не показывает, но сама модель — список + синхронное выделение + группы-папки — это то, что нужно взять;
- **Frame** (Shift+P / Ctrl+J) — визуальная группа нод на холсте, рамка с подписью;
- **Node group** (Ctrl+G, Tab — войти) — группа как одна нода с входами и выходами. Пересекается с `docs/backlog/2026-10-26_composer-as-node-group.md`.

Ещё аналог — панель слоёв в Figma / Illustrator: список, выделение, группы, порядок.

До разработки решить:
- группа — это только папка в списке, frame на холсте или node group, который меняет граф. Только node group попадает в `ToastGraph` и contract;
- где живут группы: в toast-файле или только в ui.

Если в blender найдётся готовая модель — берём оттуда поведение, как и остальные use-cases (`docs/backlog/2026-10-28_drop-node-onto-link.md`, раздел про спецификацию из blender).
