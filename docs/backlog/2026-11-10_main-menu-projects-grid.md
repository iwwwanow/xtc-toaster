# Главное меню: сетка актуальных проектов с превью

Идея пользователя от 10.11. При открытии приложение показывает главное меню: все актуальные проекты сеткой uiu / owo, у каждого карточка с превью. Проекты хранятся в `localStorage`. Сейчас там лежит один редактор под ключом `xtc-toaster:editor` (`packages/web/src/persist.ts`), а нужен список проектов, у каждого свой граф, настройки экспорта и превью. Превью стоит хранить маленьким, в отдельной записи от графа: квота `localStorage` около 5 МБ, а png в 2 МП весит мегабайты. Картинка проекта живёт на сервере по TTL (24 ч), поэтому у старого проекта граф останется, а input покажет `image not found`. Здесь главное меню пересекается с форматом «проект = граф + картинка» (`docs/backlog/2026-10-13_toast-export-with-image.md`).
