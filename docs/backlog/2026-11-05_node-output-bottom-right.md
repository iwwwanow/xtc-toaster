# Пиксельный выход ноды — в правом нижнем углу

Пиксельный выход каждой ноды должен стоять в правом нижнем углу, а не на линии заголовка, как сделано 05.11 (`.svelte-flow__node > .svelte-flow__handle-right` в `packages/web/src/app.css`). Причина переноса остаётся: выход не должен совпадать с разъёмом параметра в строке, поэтому по центру ноды его оставлять нельзя. Когда правило поменяется, нужно обновить и решение в конце `docs/sprints/sprint-5.spec.md`. Подробности о переносе — `docs/diary/2026-11-05_animation-web.md`.

Сделано 06.11 (`feat/animation-web`).
