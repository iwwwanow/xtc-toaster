# QA — спринт 4: composer (ветка `feat/composer`)

Ручная проверка перед мержем. Только хрупкие места: автотесты зелёные, здесь то, что видно лишь глазами или живёт на стыке web ↔ server.

Стек: `docker compose up -d` → http://localhost:5173, poppies загружается сам. `RENDER_MAX_LAYERS` в dev — 4 (fallback).

## 1. Разветвление и копии (server)

- [ ] input → 3 цепочки → composer (3 строки) → output: рендерится, все 3 слоя видны
- [ ] **fill или tint в одной ветке не протекает в соседнюю**: ветка A — fill, ветка B — напрямую из input. В B исходная картинка, не залитая (fill / tint пишут в буфер на месте, server отдаёт копию всем потребителям, кроме последнего)
- [ ] opacity в одной ветке → её слой полупрозрачный, остальные нет

## 2. Строки composer

- [ ] перетащить строку `⠿` на другое место → **связь едет вместе со строкой** (провод перерисован к новой позиции, не висит на старой), картинка меняется
- [ ] после перестановки у новой нижней строки select заблокирован, у бывшей нижней разблокирован и сохранил свой режим
- [ ] `+ layer` → строка сверху, провода остальных строк не съехали
- [ ] `×` на средней строке → строка и её провод исчезают, остальные провода на своих местах; `+` после этого — новая строка без чужого провода
- [ ] смена blend mode (`add`, `lch-hue`) → перерисовка
- [ ] во время рендера кнопки / select / `⠿` заблокированы

## 3. Связи

- [ ] провод на занятый вход (нода или строка composer) → **заменяет** старый, старый пропадает
- [ ] перетащить конец существующего провода на другую строку / ноду → переехал, на старом месте ничего не осталось; бросить в пустоту → провод удалён
- [ ] цикл (A → B → A) и провод в input не рисуются — handle не подсвечивается
- [ ] строка без провода пропускается; composer без единого провода → ошибка на composer

## 4. Лимит слоёв

- [ ] 4 связанные строки — рендерится; 5-я → `render-error` на composer
- [ ] composer внутри composer (2 + 3 строки = 5) → ошибка тоже есть (лимит общий на рендер)

## 5. Экспорт / импорт

- [ ] граф с composer и развилкой → export → import: тот же граф, строки в том же порядке, провода на своих строках, раскладка по колонкам без наложений
- [ ] старый экспорт спринта 3 и signac импортируются как раньше
- [ ] руками испорченный .json (два провода в один вход / цикл) → понятная ошибка, граф не сломан
